. Clone the repository:
   git clone https://github.com/yawinders/AssignmentSTEMROBO.git
Navigate to the project directory:
cd AssignmentSTEMROBO
npm install
Start the development server:
npm run dev
Open your browser and go to http://localhost:3000.

Project uses vite.

No known issues at the moment.

Approximately 2-3  hours to complete the assignment, including setup, coding
